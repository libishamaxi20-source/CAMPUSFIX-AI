# CampusFix AI V2

CampusFix AI V2 is a full-stack Flask application that turns issue reporting into an automated, AI-triaged workflow backed by a real SQLite database.

## Quickstart (Mac Terminal)

```bash
cd ~/Downloads/CampusFix-AI-V2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
